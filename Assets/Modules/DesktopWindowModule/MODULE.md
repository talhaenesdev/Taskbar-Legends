# DesktopWindow

## Purpose
Turns the player window into a small borderless, always-on-top strip docked above the Windows taskbar, and moves it when dragged. It also sets the window's opacity and stay-on-top, registers the game to start with Windows (HKCU Run key, current user only), and hides the window behind a notification-area icon.
