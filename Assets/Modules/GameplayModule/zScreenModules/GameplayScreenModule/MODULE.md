# GameplayScreenModule

## Purpose
The System window the idle battle is shown in: hero level, rank, HP and EXP bars, stats, the arena with damage numbers, the battle log and System notices. Dragging it moves the desktop window.

## Concepts
gameplay screen, HUD, system window, hp bar, exp bar, stat panel, battle log, damage popup, announcement, drag window

## Decisions
- Laid out for the 560x180 strip `MainConstants` docks the window as; the ScreenManager's CanvasScaler in MainScene is set to that reference resolution.
- The prefab's art is placeholder: the white `SPR_Pixel` sprite tinted, and the built-in legacy font.

## Known gaps
- The Bloodlines - Dark UI pack was not in the project, so the screen is not skinned with it yet.
